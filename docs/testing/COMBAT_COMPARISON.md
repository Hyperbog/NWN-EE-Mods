## Phase 4.1C isolation gate

Distinguish (1) native local attack selection/playback not occurring, (2) native pose/attachment motion exists but first-person framing/clearance obscures it, (3) user refers to former synchronized eye motion, (4) input/facing suppresses or interrupts attack. No causal conclusion from static diff alone. Use bounded read-only local-player telemetry and matched visual observations: attack identity/clip and phase where supported, body/weapon pose change and shared render correction, actor/eye transform, clearance accepted/rejected and relevant gates, actual attack result vs reticle. Use existing C3C diagnostics first; they report animation ID, requested shift, trust/rejection and eye, but do not establish clip execution or attachment pose. Compare on matched character/weapon and repeat with differing rigs/equipment. Keep ADR-001 fixed eye; if actual desired historical behavior requires independent animated eye displacement, resolve design explicitly rather than silently changing it. Do not install old R3 or edit current runtime in this phase. No universal compatibility claim or speculative patch. Exact full R3 tree remains unverified; additional recovery only if necessary to discriminate cause.
