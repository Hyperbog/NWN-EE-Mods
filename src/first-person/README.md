# Fix14D J4 — First-person NWNCX source overlay

This folder mirrors the `managed/` subtree of the matching NWNCX:EE checkout. The source is designed to be integrated into that project, **not** compiled or installed independently. The verified development baseline is described in [J4 documentation](../../docs/FIRST_PERSON_J4.md).

**Publication status:** initial documentation and the post-native-walk jump bridge have been published. Remaining source must be exported from the verified Windows J4 checkout before this snapshot is complete. No stable binary release is provided.
